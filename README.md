# Awesome TV

A clean-room, modern replacement for [ErsatzTV](https://ersatztv.org/): turn a personal media library into live TV channels and stream them to Plex, Jellyfin, Emby, and any IPTV client.

**Status:** Phase 1 complete; Phase 2 underway with the broadcast-control UI, Jellyfin sync, HDHomeRun output, collections, and weekly programming blocks.

**Direction:** all-in-one, deep ErsatzTV parity in v1, Rust backend + React UI, our own streaming engine, local/Jellyfin/Plex/remote sources, Plex/Jellyfin/Emby/Channels/Kodi/TiviMate clients, multi-arch x86 + ARM, MIT or Apache-2.0.
