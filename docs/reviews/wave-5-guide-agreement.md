## Precision contract

The [XMLTV DTD](https://github.com/XMLTV/xmltv/blob/master/xmltv.dtd) defines timestamps through whole seconds and an optional timezone; this server emits `YYYYMMDDhhmmss +0000`. For XMLTV compare each stored endpoint after floor division by 1000 to UTC seconds; the encoded instant is 0–999 ms earlier. Public guide timestamps retain exact stored milliseconds. The implementation uses Euclidean division, including for pre-1970 timestamps. Adjacent stored boundaries remain adjacent after this common conversion; a positive interval wholly within one second can collapse to zero duration. The fixed test explicitly demonstrates that limitation; no fractional XMLTV extension is claimed or introduced. No policy for representing such short programmes without loss is established.

The formerly ignored five-item regression now passes: consecutive Alpha broadcasts across a cycle boundary remain distinct in both projections before and after renewal.
